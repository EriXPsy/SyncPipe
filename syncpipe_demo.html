01 / 背景 · 关系健康

身体、情绪、睡眠，
已经被测到了极致。

过去十年，可穿戴把单人生理数据变成了消费级健康服务——而且越做越深。 这不是预言，是已经发生在货架上的事：

Apple Watch
ECG · 血氧 · 睡眠分期

2018 年，它的 ECG app 与房颤提示走 FDA De Novo 通道获批（Class II，属器械 clearance、非药品 approval）——消费手表第一次把单导联心电装进手腕；睡眠分期、血氧、乃至「正念」情绪记录，也已覆盖数亿人。

Oura / Whoop
HRV · 恢复 · 压力

靠 HRV、静息心率、体温、睡眠，算出每晚的「恢复 / 准备度」分，做成订阅生意——身体量化本身，就成了产品。

下一步去哪
关系层

当单人指标被卷到天花板，关系这一层却还空着——它是最被低估、却反复被证明与寿命和健康强相关的因子之一。

所以，为什么敢说产品必然会采纳同步性研究

厂商已经在把生理与情绪科学做成生意（HRV、压力、睡眠分期全是证据）。 而关系健康，正从一个学术话题变成公共议程——2023 年 5 月，美国外科总长 Vivek Murthy 发布 advisory 《Our Epidemic of Loneliness and Isolation》，把社交孤立与孤独定性为公共卫生危机； 340 万人元分析：孤独 / 隔离 / 独居分别 +26% / +29% / +32% 早逝风险（Holt-Lunstad 2015）。市场往「关系健康」走，只是时间问题； 只是今天所有设备都停在一个人里，关系那一层，空白。

「两个人之间到底有没有真的连上、连成了什么样」——正是同步性研究想回答、却一直没被严谨回答的问题。 SyncPipe 想做的，是把这片空白接起来。

02 / 问题 · 科研线 × 市场线

两条线，
指向同一个缺口。

科研侧和市场的痛点不同，但结论汇到一处：没有人把「双人生理互动」可靠地测出来。

科研线 · 方法学危机

同步性「测不准」，证据就不可信

领域里最常用的做法，要么只做朴素互相关（近年多人穿戴研究仍这么干）， 要么用 SUSY、rMEA 这类带 surrogate 的工具—— 但它们是单指标 / 单模态，没有多级证据链、没有验证性条件对比、没有跨特征 FDR 校正。

后果：混杂控制缺失（分不清真耦合 vs ISC / 共在假象）、 无法分离真实耦合。大量「同步性效应」可能只是方法学假象。
市场线 · 碰不了

穿戴狂卷「个人」，无人碰「双人」

想想真实的使用场景：你在 Apple Health 里看自己的心率，一目了然； 想看「你和伴侣相处时，俩人身体的同步」？没有入口。

三道真实的墙：① 双人数据要双方同意、跨账户，比单人隐私难一个量级； ② 关系是最亲密的数据，卖你手表的厂商不适合同时当你们关系的裁判； ③ 测「同频与否」第一步得先证明「信号里真有同步」——这步消费穿戴从没做过，也发不出可信的测量结论。
两个缺口，同一种解法：
一套标准化、可审计、可证伪的双人同步性测量基础设施。

这恰好有一个先例可参照—— DPABI 当年把脑影像分析从「各实验室自写脚本」变成「标准化开源工具」， 并据此建起了大数据社区。SyncPipe 想做同步性领域的那把标准尺—— 先有可信的测量底座，下游的研究、临床、组织应用才有地方落脚。

朴素互相关

消费穿戴常用

JMIR 2024 一篇夫妻穿戴研究，11 对、用 cross-correlation，作者自己写「需更大样本复制」。 撑不起面向消费者的服务。

SUSY / rMEA

科研级但有天花板

SUSY（双变量 WCC + surrogate）、rMEA（动作能量 WCC + surrogate）有 null 模型， 但单指标单模态、无 L2 验证性、无 FDR 族校正。

SyncPipe 的差异

多级链 + 验证 + FDR

多模态、三段证据链（存在→结构→条件）、FDR/BH 族校正、claim-ceiling 纪律、 可审计 null 模型。这是一个新品类，不是又一个脚本。

03 / 技术路径 · 怎么测准

三条流水线，
把「默契」变成可验证的结论。

SyncPipe 不是单个算法，而是三条流水线构成的测量基础设施。第三条（推断）是核心。

Feature Pipeline

从信号到特征

原始多模态生理信号 → 对齐、滤波 → 提取 WCC 轨迹与特征 （同步幅度、episode 驻留时长、进出切换率、形态学描述）。

Computational Pipeline

从轨迹到结构

计算滑动窗交叉相关（WCC）轨迹、检测同步 episode、刻画形态—— 把「平均相关」升级成「同步长什么样」。

Inference Pipeline

从结构到结论

三段证据链 L0→L1→L2，每一段都配一个「反方律师」专门负责找出结论可能是假的理由。 下面用「身体同频」的比喻讲清它怎么解开科研问题、又怎么解开市场问题。

L0有没有在同步
两个人的身体信号，真的出现了「同频」吗？ 反方律师的手法：把两人各自的数据打乱重排——保留每个人自己的节奏，只切断两人之间的对应关系。 如果打乱后还能同步到这个程度，那原来的同步就不算证据。这就是存在性 gate，过不了后面免谈。
L1同步长什么样
是真的一段段「连上了」，还是平均下来碰巧偏高？ 真有互动时，同步应该一段一段成型：连上一会儿、断开、又连上—— 而不是全程比基线高那么一丁点。这一关专门检验同步有没有「成段」的结构。
L2换场合还在不在
这份同步，会随两人在做什么而变化吗？ 最关键的一关：把搭档打乱重配（真默契应消失）、把时间轴错开（真互动应消失）。 如果两种破坏之后同步还在，那它是环境造成的，不是人际连接。

三关的「反方律师」互不相同，证据不能混算——这是很多研究出错的地方， SyncPipe 在代码层强制分开。只有全过三关的，才允许叫确认性发现；其余明确标为探索性。

同一套机制，解开两条线

对科研：它把「同步性是否真实、是否结构化、是否因条件而异」从一句口号变成可审计的流程—— 能分离真实耦合与 ISC / 共在假象，让结论可被推翻、可被重复。

对市场：穿戴厂商若自己发一个「夫妻同步分 73%」，会遭科学与监管双反噬 （FDA 的数字健康技术框架，要求穿戴测到的生理信号做 fit-for-purpose 验证——分析性 + 临床验证，才能进临床证据）。测量空白，恰恰是大厂进不来的原因。 SyncPipe 不做硬件、不卖「连接分」，而是做中立的、可信的测量层—— 谁先有这把标准尺，谁就握住所有关系健康应用的测量关口。

04 / 实证能力 · 开源真实数据

SyncPipe 在真实数据上，
挖出了比「平均同步」更多的东西。

下面所有数字来自公开双人生理数据集 LERIQUE（2024）， 用 SyncPipe 当前代码跑出。目的只有一件事：展示能力—— 同样的数据，SyncPipe 能额外给出朴素方法给不了的结构特征。

先看一个反直觉的结果

朴素做法只报一个「平均同步」数字（mean_synchrony）。我们在此之上，逐步叠加 SyncPipe 的关系结构层特征（同步幅度、episode 驻留、进出切换率）， 看它能不能把「静息 vs 任务」两种状态区分开。

在 RESP（呼吸）通道上，朴素指标只有 0.38——等于瞎猜； 加上结构层后涨到 0.88。关系结构，才是信号本身，不是噪声。

朴素「平均同步」几乎分不出状态（RESP 仅 0.38，比瞎猜还差）； 叠上 SyncPipe 的结构层，三条通道命中率全线上扬——关系是一段段「连上又断开」的结构，朴素平均把它抹平了。

数据：LERIQUE 2024，n≈54–62 / 模态；5 折交叉验证逻辑回归 AUC。 任务：区分 rest（静息）与 trials（任务）。基线 = 朴素 mean_synchrony；逐步 + L0→L1 结构描述子。 诚实边界：小样本、数据受限，且重跑中检出疑似泄漏会把估计往下压； 这是「原理验证」，不是统计稳健的验证结论。

再描绘「同步长什么样」

同一批 LERIQUE 数据，SyncPipe 把每条同步轨迹的形态聚成了三类—— 这正对应 L1 那关想回答的「同步长什么样」。

簇 0 · 深而稳同步强，且长时间驻留
簇 1 · 几乎没连上幅度低，基本只是漂移
簇 2 · 连得很带劲幅度高，但频繁进出

把每条「两人有多同步」的曲线按形状分了三类——深而稳 / 几乎没连上 / 连得很带劲但进进出出。 朴素方法只给一个「平均」数字，把三种相处模式混成一个数；SyncPipe 把它们分别认了出来。 形态学聚类（LERIQUE，n=176 traces，EXPLORATORY / 小样本）。

这一节我们只证明一件事：
SyncPipe 能比朴素方法多看到一层关系结构。

至于「这些结构特征，是否真的对应关系质量或健康程度」—— 这需要严谨的科研验证，本 demo 不做任何断言。 把这一步说成已证实的结论，正是我们不做的那种事。它属于下一步的科研方向。

05 / 为什么是 SyncPipe · 为什么是现在

不是又一个同步性 App，
而是关系的测量层 / 认证层。

为什么是 SyncPipe（护城河）

师承 DPABI，知道怎么把方法做成平台。DPABI 当年把脑影像分析从「各实验室自写脚本」变成标准化开源工具， 并据此养出一个大数据社区——我们亲眼见过这套玩法：不止是会写软件，更是会搭测量平台、建基准、做可复现、运营生态。 SyncPipe 想做的，是同步性领域同一个位置的东西：不是又一个脚本，而是一把别人绕不开的标准尺。

价值不依赖同步性看涨。SyncPipe 是测量仪器——连「同步性不存在」这种 null 结果， 都需要被严谨地测量出来。即便未来证明同步性预测力有限，世界仍需用它严谨地确立这一点。 这把它和所有「同步性 App」竞品区隔成一个不同品类。

为什么是现在（时间套利）

三件事刚同时就位：① 多模态穿戴把高质量生理信号从实验室搬到了日常，采集成本掉了一个数量级以上； ② 监管把门槛抬高——FDA 的数字健康技术框架要求穿戴生理信号做 fit-for-purpose 验证，这恰是 SyncPipe 的价值锚； ③ 双人信号已被证明真实存在（心率联动关联慢病管理），却没有任何可信测量工具。 数据到了、监管逼你测准、关系层空白——窗口就开在这三者的缝隙里。

学术侧
有方法

同步性研究十余年积累，却散在各实验室自写脚本里，不可复现、不可审计。这正是要填的洞。

商业侧
有信号

情感计算、社交信号分析已有创业公司在做，但多是单人相关指标，尚未触及「双人可证伪」。

卡位
做标准

不抢应用层快钱，先坐实「测量标准」——应用可以很快，但底层不可信，整条路后面会推倒重来。

关于团队与融资的具体诉求，我留到当面展开—— 此刻先让方法与时机自己说话。
