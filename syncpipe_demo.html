你的手表，读懂一个人。

01 / 缺口 · 数据已经到位，证据基础设施没有

市场不缺传感器。
缺的是把多人数据变成可信决策的中间层。

越来越多产品能同时看到患者—治疗师、伴侣、护理者—患者、驾驶员—座舱、人与机器人。 真正卡住落地的，不是“能不能算相关”，而是结果能否复现、审计、解释，并经得住共同刺激、漂移和伪迹的反驳。

今天的供给

硬件平台输出更多信号

心率、皮电、呼吸、动作、眼动持续增长；AI 让一次性分析脚本生成得更快。

但每个团队仍在重写对齐、缺失、阈值、null、排除与报告。数据规模化了，错误也规模化了。
真正的采购需求

不是一个“同步分”，而是可交付证据

研发负责人、临床试验团队、IRB/审评、算法合作方需要知道：算了什么、排除了什么、最多能说什么。

一条结果必须带着 provenance、QC、反例测试、统计不确定性和 claim boundary 一起交付。
SyncPipe 的切口：
Pair Data → Evidence API

DPABI 证明了标准化分析基础设施可以重塑一个研究领域。SyncPipe 借鉴的是路径，不是宣称已经拥有同等影响力： 先从高痛点科研与临床研发工作流切入，再向需要多人时序证据的产品团队扩张。

04 / 市场入口 · 先卖“可信交付”，再卖“关系洞察”

不从消费者“默契分”起步。
从已经为证据质量和返工成本付费的人开始。

BEACHHEAD 01
科研团队 / CRO

双人心理生理、社会神经科学、治疗过程、行为同步项目。需求是标准分析、协作复现、方法报告和审稿响应。

BEACHHEAD 02
数字疗法 / 临床研发

患者—治疗师、患者—护理者、共同调节研究。需求是 protocol-locked pipeline、数据 provenance、站点一致性和审计包。

EXPANSION 01
穿戴 / 传感 OEM

不是直接给消费者“关系好坏”，而是向算法研发团队提供双人时序 evidence SDK、benchmark 和白标审计引擎。

EXPANSION 02
高可靠团队 / 人机系统

驾驶舱、协作机器人、训练与人因研究。需求是多人协调信号的离线验证与模型评估；属于后续场景，不是当前已验证能力。

关系健康可以是长期愿景，但短期收入锚点是研发效率、跨团队交付、审计与私有部署。

06 / 壁垒 · 不是一个相关公式

算法容易复制。

CONTRACTS

Endpoint × Null × Claim

每个 endpoint 必须绑定估计对象、null、适用边界和禁止声明。未来扩展不是多加一个按钮。

VALIDATION ASSETS

独立动态、共同刺激、漂移、伪迹、错误搭档和时长偏差，持续沉淀成回归资产。

BACKUP / 5 分钟 Q&A

最难的问题，
不回避，直接变成里程碑。

“这不就是一个 Python 包？”
今天是开源 engine，产品是证据工作流。 Engine 负责方法信任；Cloud/Private 负责项目向导、协作复现、自动报告、权限、部署和 connector——这些才是付费层。
“为什么不用 ChatGPT 临时写分析？”
AI 能生成代码，不能自动保证跨项目使用同一个 estimand、null、排除政策和 claim ceiling。SyncPipe 把方法治理从聊天记录变成版本化、可测试、可迁移的合同。
“科学上验证了吗？”
完成内部 ground-truth、公开数据重分析、对抗性负对照和 521 项工程/方法契约测试；尚未完成独立第三方 own-data validation。下一里程碑是外部报告，不是继续堆指标。
“市场是不是太窄？”
Beachhead 有意窄：已经采集双人连续信号、又必须交付可信证据的科研和临床研发团队。底层能力可扩到穿戴 OEM、高可靠团队与人机系统，但扩张要由付费 pilot 证明，不用 TAM 幻觉代替。
“护城河在哪里？”
不是 WCC。潜在壁垒是 endpoint-null contracts、对抗性 benchmark、设备/模态 connector、历史迁移、外部复现记录和领域工作流网络。目前是可形成壁垒的资产，不是已经形成的垄断。
“你不是工程师，为什么是你？”
我在问题现场，知道研究者最容易把统计结果误写成心理结论。我用 AI 加速工程学习，也用测试、负对照和外部验证约束 AI。融资的意义之一，就是补齐科研软件工程、统计方法和商业化团队。
